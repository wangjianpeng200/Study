## 概念详解

### 1. 右值引用 (Rvalue Reference)

在C++11之前，C++只有左值引用（lvalue reference），使用`&`符号表示。C++11引入了右值引用（rvalue reference），使用`&&`符号表示。

#### 左值和右值

- **左值（lvalue）**：有名字的变量，可以取地址，可以被赋值。
- **右值（rvalue）**：临时对象或字面量，没有名字，不能取地址。

```cpp
int a = 10;        // a是左值，10是右值
int& lref = a;     // 左值引用
int&& rref = 20;   // 右值引用
```

### 2. 移动语义 (Move Semantics)

移动语义允许将资源（如动态分配的内存）从一个对象"移动"到另一个对象，而不是进行深拷贝。这可以显著提高性能，特别是在处理大型对象时。

#### 移动构造函数和移动赋值运算符

移动语义通过两个特殊成员函数实现：

1. **移动构造函数**：`MyClass(MyClass&& other)`
2. **移动赋值运算符**：`MyClass& operator=(MyClass&& other)`

这两个函数接受一个右值引用参数，表示它们可以从临时对象"窃取"资源。

#### 移动语义的优势

- 避免不必要的深拷贝
- 提高程序性能
- 减少内存分配和释放的次数

### 3. 完美转发 (Perfect Forwarding)

完美转发允许函数模板将参数"完美"地转发给另一个函数，保持参数的值类别（左值或右值）不变。

#### std::forward

`std::forward`是实现完美转发的关键，它能够保持参数的值类别：

```cpp
template<typename T>
void wrapper(T&& arg) {
    process(std::forward<T>(arg));  // 保持arg的值类别
}
```

#### 完美转发的应用

- 避免不必要的拷贝或移动
- 保持函数调用的语义一致性
- 实现通用的工厂函数和包装器
